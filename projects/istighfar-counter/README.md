# Istighfar Counter

[Live on Google Play](https://play.google.com/store/apps/details?id=com.istighfar.counter).

- `assets/preview.webp` — portfolio card thumbnail
- **[assets/screenshots/themes/](assets/screenshots/themes/)** — five appearance themes (Emerald, Sandstone, Rosewood, Midnight, Obsidian)
- **[assets/screenshots/app-screens/](assets/screenshots/app-screens/)** — Today, History, Menu, and Settings
- **[assets/screenshots/arabic/](assets/screenshots/arabic/)** — three Arabic-language screens

All 13 JPG screenshots are registered in the portfolio gallery in `initImages() → projectImages.istighfar` in the repository-root `index.html`. The themes appear first, in a consecutive group with a clickable thumbnail selector.

**New screenshots:** Upload them to the matching directory using GitHub's **Add file → Upload files** and then update the gallery entries.
